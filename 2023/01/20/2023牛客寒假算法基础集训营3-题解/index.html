C. 忽远忽近的距离

题面

先看n比较好的情况.

n = 1, 2, 3 时都不行. n = 4 时， 3, 4, 1, 2 满足题意. n = 5 时， 4, 5, 1, 2, 3 满足题意. n = 6 时， 4, 5, 1, 6, 2, 3 满足题意. n = 7 时，易证此时没有可行构造.

发现如果 4 ∣ n ，设初始状态下 ai = i(i=1,2,...,n) 那么可以四个一组，将 i 与 i + 2 交换，将 i + 1 和 i + 3 交换，这样可以满足题意.

如果 4 ∤ n ，分类讨论n模4的余数.

若 n ≡ 2(mod4)即n = 4k + 2 ，n = 4(k−1) + 6 ，前面 4 * (k−1) 个数按四的倍数的情况搞，剩下6个按 n = 6 的构造.

若 n ≡ 1(mod4)即n = 4k + 1 ， n = 4(k−1) + 5 ，同理，使用 n = 5 的构造.

若 n ≡ 3(mod4)即n = 4k + 3 ，n = 4(k−2) + 6 + 5 ，前 4(k−2) 个用四的倍数的构造，然后接一个 n = 6 的构造，再接一个 n = 5 的构造.

D. 宿命之间的对决

题面

初看上去不太好做，试试 n 比较小的情况.

发现在 n = 1, 2, ..., 8 的时候都是偶数先手赢，奇数后手赢，可以猜测这是普遍规律.

尝试证明，用第二类数学归纳法：

设对于 n = 1, 2, ..., 2k 都是偶数先手赢，奇数后手赢. n = 2k + 1 时，选择的因子只能是奇数，那么 n 减去这个因子得到的 n′ 便是偶数， n′ ∈ {1, 2, ..., 2k} ，此时相当于小紫先手，偶数先手胜，所以 n = 2k + 1 时，后手胜.

n = 2k + 2 时，选择因子 1 ， n′ = n − 1 = 2k + 1 ，此时相当于小紫先手，但 n′ 为奇数，后手胜，所以 n = 2k + 2 时，先手必胜.

综上，由归纳原理，对于 n = 1, 2, ... ，有 2 ∣ n 时，先手必胜， 2 ∤ n 时，后手必胜.
